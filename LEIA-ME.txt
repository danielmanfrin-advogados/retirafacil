RETIRAFÁCIL — SITE ESTÁTICO

O projeto usa somente HTML, CSS e JavaScript puros. Não usa React, Vite, framework, npm ou etapa de build. A Vercel deve usar Framework Preset: Other, comando de build vazio e diretório de saída na raiz do repositório.

ESTRUTURA

- index.html: página inicial.
- servicos/*/index.html: páginas de serviços.
- bairros/*/index.html: páginas locais de Ribeirão Preto.
- sobre/index.html, perguntas-frequentes/index.html e politica-de-privacidade/index.html: páginas institucionais.
- img/: fotos JPG compactadas usadas pelo site.
- style.css: folha de estilos única e compartilhada.
- tracker.js e config.js: rastreamento e configuração editável.
- apps-script/Code.gs: script da planilha Google.
- sitemap.xml, robots.txt e llms.txt: descoberta por buscadores e mecanismos de IA.
- vercel.json: URLs limpas e barra final.

CONFIGURAÇÃO DO WHATSAPP E RASTREAMENTO

Edite somente os campos whatsapp, telefone, mensagem, cidade e endpoint em config.js. Use somente dígitos no telefone, com 55 + DDD + número. O endpoint já está apontado para a implantação do Apps Script fornecida.

No Google Sheets, abra Extensões > Apps Script, cole apps-script/Code.gs, execute setup() uma vez e autorize. Depois vá em Implantar > Gerenciar implantações > editar a implantação existente > Nova versão > Implantar. Use acesso “Qualquer pessoa”. A URL /exec continua a mesma.

O tracker registra somente dados técnicos e de campanha: site, nicho, ação, posição, página, origem, UTMs, dispositivo, tela, idioma, detalhe e sessão aleatória. Não coleta nome, e-mail, CPF ou cookies de publicidade.

PUBLICAÇÃO NA VERCEL

Importe o repositório do GitHub, selecione Framework Preset: Other, deixe Build Command vazio e defina Output Directory como a raiz do projeto. O vercel.json já define cleanUrls=true e trailingSlash=true. Toda página real fica dentro de uma pasta com index.html e deve abrir com barra final.
